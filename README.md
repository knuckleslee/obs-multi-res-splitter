# obs-multi-res-splitter（多螢幕投影）

OBS Studio 外掛。抓取主螢幕畫面一次，依每台副螢幕的解析度自動裁切並全螢幕投放；副螢幕或主螢幕斷線重接後會自動恢復。

需求：Windows 10/11、OBS Studio 31.1 以上（64 位元）。

## 安裝

1. 到本專案 GitHub 頁面的 **Actions** 分頁，點最新一次成功的 `Push` 執行紀錄，在最下方 **Artifacts** 下載 `obs-multi-res-splitter-…-windows-x64` 壓縮檔。
2. 關閉 OBS，把壓縮檔裡的 `obs-multi-res-splitter` 資料夾解壓到：
   `C:\ProgramData\obs-studio\plugins\`
   （結構應為 `C:\ProgramData\obs-studio\plugins\obs-multi-res-splitter\bin\64bit\obs-multi-res-splitter.dll`）
3. 開啟 OBS，選單「停駐視窗」→ 勾選「多螢幕投影」。

## 使用

### 主螢幕（訊源）
輸入主螢幕的寬、高，或按「偵測」從清單挑選。外掛只依這組數字找主螢幕，不理會 Windows 認定的主螢幕；畫面以 DXGI 擷取，且不擷取滑鼠游標。

### 輸出列
| 欄位 | 說明 |
|---|---|
| 啟用 | 取消勾選就不投放這一列 |
| 名稱 | 自訂，方便辨認 |
| 寬／高 | 這台螢幕的解析度；直放螢幕請輸入轉向後的數字（例如 1440×2560）。同一個解析度只能有一列 |
| 偵測 | 跳出目前接著的螢幕清單，點選帶入解析度，可逐台「識別」 |
| 模式 | **來源**：裁切主螢幕畫面投放；**場景**：投放你在 OBS 自己做好的場景 |
| 對齊（來源模式） | 開啟即時預覽，用紅框決定取樣位置：拖曳、九宮格、或輸入左右上下裁切值 |
| 場景（場景模式） | 選擇要投放的場景 |
| 套用相同解析度 | 勾選：所有這個解析度的螢幕都播；不勾：只播偵測到的第一台 |
| 自動投放 | 勾選：OBS 啟動時自動投放，螢幕斷線重接後自動補回 |
| 狀態 | 投影中／未接上／已接上（未投放）等 |

### 來源模式的裁切規則
- 記住的是**相對位置**（例如「中下」），裁切值依主螢幕與輸出解析度自動換算，換主螢幕不用重設。
- 輸出比主螢幕小：1:1 原尺寸取樣。
- 輸出任一邊比主螢幕大：取與輸出同比例、能放進主螢幕的最大範圍，再放大填滿。

### 場景模式
OBS 所有場景共用同一個畫布解析度。外掛會取場景**左上角**與螢幕同尺寸的範圍投放，所以：
- 畫布要至少和最大的場景模式輸出一樣大（設定 → 影像 → 基礎畫布解析度）。畫布不足時狀態欄會提示。
- 給小螢幕的場景，內容排在左上角對應範圍內即可。

### 其他按鈕
- **重新投放**／**關閉全部投影**：也可在 OBS「設定 → 快速鍵」綁按鍵（「多螢幕投影：…」）。
- **識別螢幕**：每台螢幕中央顯示解析度與型號 3 秒。
- **匯出／匯入設定**：搬到其他電腦用。場景本身要另外用 OBS 的場景集合匯出。

## 自動恢復的運作方式
- 螢幕一有變動，跑到錯誤螢幕（例如被 Windows 搬到主螢幕）的投影會立刻隱藏。
- 約 2.5 秒後依解析度重新配對主螢幕與各輸出，重開需要的投影；之後每 4 秒檢查一次，處理解析度較晚才穩定的情況。
